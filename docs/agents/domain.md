# Domain docs

HyProC is a single-context project.

Before working on domain concepts, read the Glossary section in AGENTS.md.
Use its vocabulary in issues, proposals, and code.

If docs/adr/ exists, read any decisions relevant to the work. Surface
conflicts with an existing decision rather than silently overriding it.

If a domain term or decision is missing, note the gap. Create or update
domain documentation when the relevant terminology or decision is settled.
